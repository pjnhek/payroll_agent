<objective>
Close the last silent-drift surface between Python and TypeScript: generate the frontend's view of
every response shape from the Pydantic models, commit it, and fail CI when it goes stale. A
hand-written interface drifts without a type error — a mistyped field simply never errors.

Purpose: SHELL-07's declared-shape guarantee expressed in the consuming language, and SHELL-06's
staleness gate.
Output: a generator script, a committed declaration file, a typed boot module, and a CI staleness
step.
</objective>

| Pydantic models → TypeScript declarations | The only place the two languages agree on a shape |
| generated artefact → repository | A committed generated file can drift from its source without any runtime error |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-48 | Tampering | a hand-edited generated declaration file | high | mitigate | The staleness gate regenerates and diffs; a hand edit fails CI, and the generator's docstring states that generated output is never hand-edited |
| T-22-49 | Information Disclosure | a model field added in Python and silently exposed without a TypeScript type error | high | mitigate | The hermetic test asserts every declared list-row field appears in the committed declarations, catching the common case with no Node required |
| T-22-50 | Repudiation | a generator that finds no models and emits a valid empty document | high | mitigate | The generator guards on a non-empty discovered model set and the hermetic test asserts the schema key set equals the package's public model set |
| T-22-51 | Elevation of Privilege | a new HTTP endpoint added to serve the document | medium | mitigate | The document is assembled from the models directly; an acceptance criterion asserts no new route module was added for it |
| T-22-52 | Repudiation | a staleness step silently skipped when a runtime is missing | high | mitigate | An acceptance criterion and a hermetic workflow assertion both require the step to carry no runtime conditional |
</threat_model>
