script. Four separate steps rather than one chained command, so a red job says which half broke.

runtime stage's build-time manifest assertion executes. Do not push the image anywhere and do not
add registry credentials; `permissions: contents: read` must remain sufficient. Add a comment naming
what this job exists to catch: the bundle output directory is gitignored, so a build from a
developer's working tree can succeed while a build from the clone cannot, and CI's clone-based build
is the only place that difference is visible before deploy.

Declare no job-level `concurrency` on either new job, and do not add a `needs:` dependency between
them — they are independent and should fail independently.

the offending paths by name and state why: the v5 milestone's auditable claim is that no money-moving
code was edited, and SHELL-08's closing diff proof in Phase 24 depends on that being continuously
true rather than checked once at the end.

Add a comment naming the removal owner: this fence is scoped to the v5 milestone and is retired at
milestone close, once SHELL-08's diff proof has been produced. Without that note a future milestone
inherits a gate nobody can explain.
