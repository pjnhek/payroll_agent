## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator-supplied query string → rendered banner | The notice channel is the only server-to-operator text channel that survives a redirect |
| test suite → merge decision | A vacuous assertion is a gate that reports green while guarding nothing |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-53 | Repudiation | an absence assertion that passes because it can no longer see its target | high | mitigate | The safety registry pins each such assertion to a named mutation, every mutation is run for real with a captured red transcript, and the coarse sweep names any entry no failure covers |
| T-22-54 | Tampering | injected operator-facing text through the notice channel | high | mitigate | The channel is server-reduced to an allowlisted label before rendering and an unknown value renders no banner; a test asserts that, and the label reducer is never read client-side |
| T-22-55 | Spoofing | a queue-failure message claiming nothing was recorded when a run row exists | high | mitigate | A test asserts the rendered retry text and asserts the absence of a nothing-was-recorded claim on the post-commit failure path |
| T-22-56 | Repudiation | a replacement pointer naming a test that does not exist | high | mitigate | A completeness test resolves every pointer to a real Vitest file and test name on disk |
| T-22-57 | Denial of Service | the safety registry wired into the real-database workflow and silently skipping | high | mitigate | The registry is hermetic and an acceptance criterion asserts it is absent from that workflow's configuration |
</threat_model>

## Flagged planner assumptions (probe rows that stay unresolved)

- **GUARD-02 / unclassified** — "an engineer can tell, for any absence assertion that still passes
  after conversion, whether it passes because the guarded content is genuinely absent or because the
  assertion can no longer see it" has no data-shape edge to probe; it is a property of the test suite,
  not of a data flow. The planner's assumption is that the two-part formulation is sufficient: convert
  by default to positive assertions, which structurally cannot go vacuous, and mutation-pin the
  residual safety subset. The residual risk the planner cannot close is that the safety subset was
  scoped by judgment — an assertion misjudged as non-safety-critical gets no pin, and its vacuity
  would go unnoticed. The coarse sweep in Task 2 is the mitigation, and any uncovered entry it names
  is surfaced rather than dismissed. Recorded, not resolved.
