## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| embedded payload → rendered DOM | Every field the island carries reaches the operator's screen through these components |
| business-supplied text → React text nodes | `business_name` and the gate reason originate outside the app |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-24 | Tampering (XSS) | `RunsPage` / badge components rendering business-supplied text | high | mitigate | Values render as React text nodes only; the raw-markup JSX attribute is lint-banned repo-wide by plan 22-03's ESLint config, so a future contributor cannot reintroduce the surface without a lint failure |
| T-22-25 | Spoofing | an empty list rendered because the mount or the payload failed | high | mitigate | The boot module throws on a missing or unparseable payload and `RunsPage` contains no catch converting that into an empty rows array; the absence is an explicit acceptance criterion |
| T-22-26 | Information Disclosure | a component reading a field the allowlist withheld | medium | mitigate | Components consume only declared `RunListRow` fields; the generated DTO types in plan 22-11 make an undeclared field a compile error |
| T-22-27 | Denial of Service | a wide table forcing horizontal page scroll on a narrow viewport | low | accept | Mitigated structurally by the scroll region; the pixel-level proof is manual, matching this repo's existing precedent, and is recorded rather than automated |
</threat_model>
